BAB 1: EXECUTIVE SUMMARY & LATAR BELAKANG PROYEK

1.1 Gambaran Umum: Sistem Vessel Risk Management (VRM) merupakan platform inti milik Marine Insurance Broker (MIB) yang didesain khusus untuk mengelola penilaian risiko armada kapal, inspeksi survei kelautan, manajemen polis mitigasi asuransi, dan resolusi kasus klaim perkapalan.

1.2 Alasan Modernisasi: Sistem sebelumnya berjalan pada CodeIgniter 3 HMVC dan MySQL 5.7. Modernisasi ke Laravel 11 dan PostgreSQL 14 berhasil dieksekusi dengan prinsip Zero Disruption (tampilan dan alur 1:1 persis) dan Zero Data Loss (seluruh 987 polis, 699 kapal, dan 1.433 item survei terpelihara utuh).

4.1 Modul Dashboard Analitik Eksekutif (/admin/dashboard)

Menghadirkan grafik 1:1 'Total Policy by Years' menggunakan Highcharts bertema kanvas gelap (#181818) dengan bar biru elektrik (#00b4d8) yang interaktif, 6 kartu KPI eksekutif, serta visualisasi pangsa pasar asuransi dan portofolio risiko.

Pemetaan UI ke Database & Relasi:
• Tabel Terkait: surveys, vessels, insurance_companies, claims.
• Relasi: surveys.vessel_id → vessels.id (N:1), surveys.insurance_company_id → insurance_companies.id (N:1).
• Logika Data: Menghitung COUNT(surveys.id) per tahun (date_of_survey) serta kalkulasi saldo klaim terbayar (settled_claim_amount).

BAB 5: MANAJEMEN PENGGUNA & HAK AKSES MULTI-ROLE (RBAC)

Sistem menerapkan Role-Based Access Control (RBAC) pada tabel users dengan enkripsi Bcrypt. Form login (/admin/login dan /login) mendukung fleksibilitas Dual-Login (Username / Email).

BAB 6: PANDUAN DEPLOYMENT & LEMBAR PENGESAHAN

6.1 Prosedur Deployment: Deployment ke server produksi 149.129.235.91:3031 dilakukan secara otomatis melalui Git: (1) git pull origin main, (2) php artisan migrate --force, (3) php artisan optimize:clear && php artisan route:clear && php artisan view:clear.

6.2 Pencadangan Data Harian: Pencadangan harian basis data PostgreSQL dianjurkan menggunakan perintah pg_dump: PGPASSWORD='VrmSecure2026Db' pg_dump -U vrm_user -h 127.0.0.1 -d vrm_modern --format=custom --file='/var/backups/vrm_modern_$(date +%Y%m%d_%H%M%S).dump'.
